# Очередь в поликлинике (Hospital Queue)

Консольное приложение на C++ для управления очередью пациентов на основе команд из текстового файла. Проект выполнен в рамках индивидуальной работы по дисциплине «Языки программирования».

## Принцип работы

Программа считывает текстовый файл с командами. В первой строке файла указано общее количество операций, а дальше идут сами инструкции:
* `+ [Имя] [Приоритет]` — добавить пациента в очередь (чем меньше число приоритета, тем важнее пациент).
* `-` — вызвать следующего по приоритету пациента на прием.

> Если у пациентов одинаковый приоритет, программа строго соблюдает правило **FIFO** благодаря внутреннему счетчику ID.

## Структура проекта

* `main.cpp` — точка входа, логика интерфейса, парсинг файла и цикл обработки команд.
* `hospital.h` — объявление структуры `Patient` и класса `Hospital`.
* `hospital.cpp` — реализация методов класса (добавление и обслуживание пациентов).
